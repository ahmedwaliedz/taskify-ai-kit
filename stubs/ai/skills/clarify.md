# 🔍 SKILL: /clarify

## Purpose
Resolve ambiguities in the spec before planning.

## Workflow
1. Review `spec.md`.
2. Generate `clarifications.md` with max 5 critical questions.
3. Label questions as `[BLOCKER]` or `[INFO]`.
4. Wait for user responses.
5. Update `spec.md` with answers.

## Output
`⏸️ Awaiting @resolved`
