# 🎯 SKILL: /specify

## Purpose
Convert a user request into a formal `spec.md`.

## Workflow
1. Analyze user input.
2. Identify core User Story.
3. Define Gherkin Acceptance Criteria (AC).
4. Outline Non-Functional Requirements (NFR).
5. Identify out-of-scope items.
6. Create `features/{slug}/spec.md`.

## Output
Print the spec and end with:
`⏸️ Awaiting @approve`
