# 📋 SKILL: /tasks

## Purpose
Break the plan into atomic, traceable tasks.

## Workflow
1. Review `plan.md`.
2. Generate `tasks.md`.
3. Each task MUST be:
   - Atomic (one responsibility).
   - Traceable (linked to `AC-X`).
   - TDD-ready (includes test order).
4. Assign IDs: `T-001`, `T-002`, etc.

## Output
`⏸️ Awaiting @approve`
