# 🚀 TASKIFY AI Kit v1.2

Welcome to Taskify. This project uses a strict, spec-driven development workflow managed by AI.

## 📂 Structure
- `.ai/`: Core rules, skills, and templates.
- `features/`: Isolated feature contexts.
- `PROJECT_CONTEXT.md`: High-level project integration map.

## 🔄 Workflow
1. `/specify`: Define requirements.
2. `/clarify`: Resolve ambiguities.
3. `/plan`: Architecture & database schema.
4. `/tasks`: Atomic task breakdown.
5. `/implement`: Code & test cycles.
6. `/closure`: Final polish & memory compression.

## 🧠 Memory Management
AI state is kept in `features/{slug}/memory.md`.
Soft limit: 150 lines. Auto-compression triggers via `/compress-memory`.
