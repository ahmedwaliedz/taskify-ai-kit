# Contributing to TASKIFY

Thank you for your interest in contributing to TASKIFY!

## Guidelines

1. **Follow the Constitution**: All contributions must adhere to `.ai/rules/constitution.md`.
2. **Phase Gates**: Never skip `@approve` checkpoints.
3. **Testing**: Run `composer test` before submitting PRs.
4. **Code Style**: Use `composer lint` to ensure code quality.

## Workflow

1. Fork the repository
2. Create a feature branch: `feat/your-feature`
3. Make changes following TASKIFY specifications
4. Run tests: `composer test && composer lint`
5. Submit a PR with clear description

## Questions

Open an issue for discussion before starting major changes.
